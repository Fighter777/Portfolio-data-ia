# Projets du portfolio Data / IA

Ce dossier regroupe les fiches de projets associées au portfolio OpenClassrooms. Elles servent de preuves de compétences et précisent le niveau d'aboutissement de chaque réalisation.

La structure est volontairement homogène :

**Contexte → besoin → données → démarche → résultats / état actuel → limites → prochaines étapes**

Les formulations distinguent explicitement :
- les **projets réalisés** ;
- les **projets expérimentaux en préparation** ;
- les **études de faisabilité / R&D** qui ne disposent pas encore d'un prototype complet.

Les éléments insuffisamment documentés sont marqués **[À compléter]** afin de ne pas inventer de résultats.
